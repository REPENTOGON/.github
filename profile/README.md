## 🧠 Overview

REPENTOGON is a native modding framework and script extender created for **The Binding of Isaac: Repentance+**. Rather than operating like a conventional Lua mod, it extends the game's underlying API with additional functions, callbacks, bug fixes, and performance-oriented improvements. The project is designed to give mod creators deeper access to game systems while enabling more sophisticated modifications and tools.

## Additional Information for Windows Users

REPENTOGON is closely tied to the version of The Binding of Isaac: Repentance+ that it supports. The official launcher can detect the Isaac executable, install the framework, and provide repair or update functions when necessary. Because REPENTOGON modifies the game's native environment, compatibility should be checked after major game updates before launching heavily modded saves.

The framework currently provides extensive additions to the Lua API, including more than 800 new or improved functions, over 200 callbacks, and numerous additional enums. This expanded interface is primarily aimed at mod developers and advanced players using modifications that depend on REPENTOGON.
